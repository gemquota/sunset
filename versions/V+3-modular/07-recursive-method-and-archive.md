# 07 — Recursive Method and Archive

The project separates three layers:

1. **Source** — the song and available evidence.
2. **Interpretation** — claims about structural and thematic relationships.
3. **Development record** — versions and Q&A showing how the interpretation changed.

The recursive method is:

```text
interpret → refine → seek support → seek disconfirmation → revise confidence → return
```

A future CIITV should state what it newly explains, which earlier claim it changes, what it makes less certain, and which competing interpretation it strengthens or weakens.
