# Retrospective foreshadowing

**Confidence:** Moderate

Retrospective foreshadowing describes the listener effect in which later context changes the apparent significance of an earlier line.

The repository uses this term for cases where an early phrase becomes more specific or consequential after the listener has encountered later material.

**Boundary:** A retrospective change in reader understanding does not prove deliberate authorial foreshadowing. The distinction between effect and authorial design must remain explicit.
