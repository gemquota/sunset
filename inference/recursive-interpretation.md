# Recursive interpretation

**Confidence:** Moderate

Recursive interpretation is the repository's description of a process in which each interpretive pass uses the result of earlier interpretation as part of the context for a later pass.

In the song analysis, later lines alter the framework through which earlier lines are understood. The song remains unchanged; the listener's representation of it changes.

**Boundary:** This establishes a plausible description of the listener's interpretive process. It does not establish that the songwriter deliberately designed the song to force this process.
