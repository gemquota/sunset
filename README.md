# sunset

A structured archive of an evolving interpretation of Jesse Welles's *Will The Computer Love The Sunset*, including essay versions, source-comment references, and interpretive context.

## Repository map

- `context/opening-discussion/interpretive-history.md`: how the interpretation developed.
- `context/reddit-comments/`: source permalinks, roles, and retrieval status for the two Reddit comments.
- `research/source-and-claim-register.md`: concepts and evidentiary cautions.
- `essays/versions/`: essay versions and an archival note about the earlier draft.

## Reading order

1. Read the interpretive history.
2. Review the Reddit provenance notes.
3. Read the source and claim register.
4. Read the revised six-part essay.

## Versioning and provenance

The revised essay is a new version and must not overwrite the earlier draft. The earlier draft was created in WritingBlock ID `62941`, but its complete text was not available among the files accessible during this export. The recovery note records that limitation rather than inventing a verbatim copy.

The two Reddit permalinks are preserved. Their exact comment bodies could not be retrieved through the available connection, so their files identify their roles and link to the originals rather than presenting fabricated transcripts.

## Editorial principles

- Keep source interpretation, user interpretation, and synthesis distinguishable where possible.
- Treat claims about songwriter intent as interpretations, not facts.
- Treat machine consciousness and future ASI outcomes as open questions.
- Preserve versions rather than overwriting earlier work.
