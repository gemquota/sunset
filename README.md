## Versioning and provenance

The revised essay is a new version and does not overwrite the earlier draft. The earlier draft was created in WritingBlock ID `62941`, but its complete text was not available among the files accessible during this export. The recovery note records that limitation rather than inventing a verbatim copy.

The two Reddit permalinks are preserved. Their exact comment bodies could not be retrieved through the available connection, so their files identify their roles and link to the originals rather than presenting fabricated transcripts.

The current essay is stored as Markdown so it can be reviewed and edited directly in GitHub. The separate local starter bundle created during this conversation contains the matching Word document; that binary document has not been added to this repository.

## Editorial principles

- Keep source interpretation, user interpretation, and synthesis distinguishable where possible.
- Treat claims about songwriter intent as interpretations, not facts.
- Treat machine consciousness and future ASI outcomes as open questions.
- Preserve versions rather than overwriting earlier work.
