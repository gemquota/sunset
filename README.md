## Version numbering and provenance

The numbering began at the iteration current when the sequence was established, which became Version 0. Earlier iterations were then added in reverse as increasing negative numbers: Version -1 is the iteration before Version 0, and so on.

The original Reddit seed is **Version -10**. Version -10 was itself recursively improved approximately 5–10 times from the true original, **Version -20**. Versions below -10 therefore do not form a linear single-step chain and must not be read as one.

**Version +1** was the first new version after numbering began. **Version +2** is the first version generated through the explicit five-question Q&A refinement process documented in `context/qna/`. **Version +3** is the first version to make the essay's reading architecture itself an explicit part of the project.

The labels record the archive's working sequence, not a claim that every negative-numbered draft is a strict one-step replacement for the next number. Versions -6A and -6B are related alternatives with different emphases.

## Editorial architecture

The project deliberately retains **one massive canonical core essay** rather than turning the argument into several independent essays. The modular editions exist for reading convenience and preserve the conceptual relationships of the core argument in smaller units.

V+3 also introduces a **line-by-line interpretation index**. The index uses the supplied song text as its source for analysis, but the repository does not reproduce the complete lyric transcript. Instead, it gives every supplied line a stable number, a succinct interpretation, and a destination in the essay. Repeated chorus lines are indexed separately because their recurrence is itself analytically significant.

## Inference confidence and citation rules

The [inference register](inference/README.md) uses four confidence levels: **High**, **Moderate**, **Low**, and **Unknown / disputed**. Confidence applies to a specific claim and describes the strength of its evidentiary basis, not whether an interpretation is objectively true.

**Both-sides citation rule:** when a comparison depends on two works, identify and cite the relevant evidence from both sides. Evidence establishing a feature of one work does not establish the corresponding feature of the other. For allusion or influence claims, textual resemblance alone is insufficient to establish authorial intent or historical influence.

## Editorial principles

- Keep source material, user interpretation, and synthesis distinguishable where possible.
- Treat claims about songwriter intent as interpretations, not facts.
- Treat machine consciousness and future AGI/ASI outcomes as open questions.
- Distinguish structural/thematic resonance from influence or allusion.
- Preserve earlier versions rather than overwriting them.
- Each CIITV should identify what it changes and what it makes less certain.
- Future versions should develop serious competing interpretations rather than only accumulate confirming evidence.
- Keep the root uncluttered: current essay + README; archive, context, and inference live in their own directories.
