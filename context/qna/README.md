# Q&A refinement track

This directory records five open questions selected to drive the next version of the interpretation. Each question begins with a proposed answer, is presented to the user for conceptual testing, and is then refined from the user's response.

The purpose is not to manufacture consensus. The Q&A is intended to expose assumptions, identify genuine changes between CIITVs, preserve uncertainty, and develop competing interpretations before they are folded into a later version.

## Process

For each question:

1. identify the unresolved issue;
2. propose an initial answer from the existing archive;
3. ask the user targeted questions;
4. record the user's answers;
5. refine the answer without silently replacing the user's uncertainty;
6. use the refined answers as inputs to the next CIITV.

The version filename records the CIITV. The Q&A record explains what changed and why. This keeps the version lineage semantically meaningful without turning filenames into miniature essays.

## Methodological constraint

A recursive interpretive process must remain capable of changing its own conclusions. A later version that merely accumulates confirming material is not automatically an improvement.

Each future CIITV should therefore consider:

- what it newly explains;
- which earlier claims it changes;
- what it makes less certain;
- which competing interpretation it defeats, preserves, or strengthens;
- and whether the new model increases explanatory power without erasing inconvenient distinctions.
